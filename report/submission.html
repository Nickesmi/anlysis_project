Language, files and how to compile

We wrote the program in C++17 and only used the standard library. The code is split into modules that share one header file:

To compile on macOS or Linux, run this inside the project folder. On Windows the same g++ line works in MinGW or MSYS2.

g++ -std=c++17 -O2 -o plagiarism src/*.cpp        # or simply: make

How to run it and which files it reads

The program does not ask for any input. It reads main_doc.txt and every *.txt file inside documents/, both taken from the folder it is started in. Documents are handled in natural order, so document2.txt comes before document10.txt. This means you run it from inside the test-set folder:

cd 1_STUDENTS_sample_set          # folder with main_doc.txt and documents/
../plagiarism_detector/plagiarism  # efficient version (default)

plagiarism brutebrute-force version, same output
plagiarism compareruns both versions, checks that their results are identical, prints both times and the speedup
plagiarism benchmark [r]times both versions on the first 1/8, 2/8, ..., 8/8 of the documents (best of r runs, 3 by default), checks that the results are equal and writes benchmark.csv
--dir <folder>optional, reads the input from another folder instead of the current one

The output goes to the console, one block per document, from most to least similar. Documents with the same rate keep their file order.

1) document18.txt   similarity 26.7%   (8 of 30 sentences)
   "<sentence in main_doc.txt>"
   "<matching sentence in document18.txt>"   [edited: replaced "should" with "must"; inserted "also"]
   ... up to the 5 most similar sentence pairs, then "... and 3 more pairs"
2) document14.txt   similarity 16.7%   (5 of 30 sentences)

Exact copies are printed as they are. For edited copies we also print which word edits turn the document sentence into the main_doc sentence. There are two helper files that are not part of the graded program: tests/selftest.cpp (run with make test; 13 checks, one of them compares the banded and the full edit distance on 200 000 random inputs) and tools/make_test_set.py, which we used to make bigger and harder test sets where we know the right answer.

// ----------------------------- data model -----------------------------

// One sentence of a document.
struct Sentence {
    std::string text;               // original text, whitespace collapsed (printed)
    std::vector<int> ids;           // its words, lower-cased, mapped to integer ids
};

struct Document {
    std::string name;               // file name, e.g. "document7.txt"

struct Corpus {
    Document main;                  // main_doc.txt
    std::vector<Document> docs;     // documents/*.txt in natural order
    int vocabularySize = 0;         // number of distinct (lower-cased) words
};

// Best match of one main-document sentence inside one document.
struct Match {
    int mainIdx = -1;     // sentence index in main_doc.txt
    int docSentIdx = -1;  // sentence index in the document (-1 = no match)
    int distance = -1;    // word-level edit distance of the pair
};

// best[d][i] = best match of main sentence i in document d.
// Both versions of the algorithm fill this table; their tables must be equal.
struct MatchTable {
    std::vector<std::vector<Match>> best;

    void init(int numDocs, int numMainSentences);
    // Keeps the pair with the smallest distance (ties: smallest docSentIdx)
    // so brute force and efficient version always choose the same pair.
    void offer(int doc, int mainIdx, int docSentIdx, int distance);
    bool operator==(const MatchTable& other) const;
};

// =====================================================================
// main.cpp
// CMP3005 Term Project - Plagiarism detector (entry point)
//
// The program takes no user input. Run it inside the folder that holds
// main_doc.txt and documents/ :
//
//   plagiarism                  efficient version (default)
//   plagiarism brute            brute-force version
//   plagiarism compare          both versions, checks equal results, speedup
//   plagiarism benchmark [r]    timings for >= 5 numbers of documents,
//                               best of r runs (default 3), -> benchmark.csv
//
// Optional: --dir <folder> reads the input from another folder.
// =====================================================================
#include "plagiarism.h"

#include <chrono>
#include <cstdio>
#include <cstdlib>
#include <string>

namespace {

using Clock = std::chrono::steady_clock;

double millisecondsSince(Clock::time_point start) {
    return std::chrono::duration<double, std::milli>(Clock::now() - start).count();
}

void printUsage() {
    std::printf(
        "usage: plagiarism [efficient | brute | compare | benchmark [repetitions]] [--dir <folder>]\n"
        "Reads <folder>/main_doc.txt and <folder>/documents/*.txt (default folder: current folder).\n");
}

void printHeader(const Corpus& corpus, const char* version) {
    long long docSentences = 0;
    for (const Document& d : corpus.docs) docSentences += (long long)d.sentences.size();
    std::printf("Plagiarism detector (%s version)\n", version);
    std::printf("main_doc.txt: %d sentences | documents/: %d files, %lld sentences\n\n",
                (int)corpus.main.sentences.size(), (int)corpus.docs.size(), docSentences);
}

}  // namespace

int main(int argc, char** argv) {
    std::string mode = "efficient";
    std::string folder = ".";
    int repetitions = 3;

    for (int i = 1; i < argc; ++i) {
        const std::string arg = argv[i];
        if (arg == "--dir" && i + 1 < argc) {
            folder = argv[++i];
        } else if (arg == "efficient" || arg == "brute" || arg == "compare" || arg == "benchmark") {
            mode = arg;
        } else if (mode == "benchmark" && std::atoi(arg.c_str()) > 0) {
            repetitions = std::atoi(arg.c_str());
        } else {
            printUsage();
            return 1;
        }
    }

    // 1. Read and preprocess all files (same for both versions).
    const auto loadStart = Clock::now();
    Corpus corpus;
    std::string error;
    if (!loadCorpus(folder, corpus, error)) {
        std::fprintf(stderr, "Error: %s\n", error.c_str());
        printUsage();
        return 1;
    }
    const double loadMs = millisecondsSince(loadStart);

    if (mode == "benchmark") {
        runBenchmark(corpus, repetitions, "benchmark.csv");
        return 0;
    }

    // 2. Find the matches.
    MatchTable table;
    double bruteMs = -1, efficientMs = -1;
    if (mode == "brute" || mode == "compare") {
        const auto start = Clock::now();
        table = runBruteForce(corpus);
        bruteMs = millisecondsSince(start);
    }
    if (mode == "efficient" || mode == "compare") {
        const auto start = Clock::now();
        MatchTable fast = runEfficient(corpus);
        efficientMs = millisecondsSince(start);
        if (mode == "compare" && !(fast == table)) {
            std::fprintf(stderr, "Error: brute-force and efficient results differ!\n");
            return 2;
        }
        table = std::move(fast);
    }

    // 3. Print the ranked documents and the running times.
    printHeader(corpus, mode == "brute" ? "brute-force" : "efficient");
    printResults(corpus, table);

    std::printf("\nReading and preprocessing the files: %.2f ms\n", loadMs);
    if (bruteMs >= 0) std::printf("Matching, brute-force version:       %.2f ms\n", bruteMs);
    if (efficientMs >= 0) std::printf("Matching, efficient version:         %.2f ms\n", efficientMs);
    if (mode == "compare")
        std::printf("Both versions give identical results; speedup %.1fx\n",
                    efficientMs > 0 ? bruteMs / efficientMs : 0.0);
    return 0;
}

// =====================================================================
// text_processing.cpp
// Reading the input files, splitting text into sentences and words,
// and mapping every lower-cased word to a small integer id with our own
// hash table (FNV-1a hash function + open addressing).
//
// All scanning is done character by character by our own code; no
// built-in text search (find, indexOf, regex) is used.
// =====================================================================
#include "plagiarism.h"

#include <algorithm>
#include <cstdio>
#include <filesystem>

namespace fs = std::filesystem;

// --------------------------- character classes ---------------------------

static bool isSpace(char c) { return c == ' ' || c == '\t' || c == '\n' || c == '\r' || c == '\f' || c == '\v'; }
static bool isUpper(char c) { return c >= 'A' && c <= 'Z'; }
static bool isLower(char c) { return c >= 'a' && c <= 'z'; }
static bool isDigit(char c) { return c >= '0' && c <= '9'; }
// Bytes >= 128 belong to UTF-8 letters (e.g. accented characters).
static bool isWordChar(char c) { return isUpper(c) || isLower(c) || isDigit(c) || (unsigned char)c >= 128; }
static bool isTerminator(char c) { return c == '.' || c == '!' || c == '?'; }
static char toLower(char c) { return isUpper(c) ? (char)(c - 'A' + 'a') : c; }

// ------------------------------ hash table ------------------------------

// Word interning table: lower-cased word -> id 0, 1, 2, ...
// Hash function: 64-bit FNV-1a, h = (h XOR byte) * prime, over the
// lower-cased bytes. Collisions: open addressing with linear probing.
// The table is doubled when it is half full, so a lookup is O(1) expected
// and O(length of the word) for hashing and comparing.
class WordTable {
public:
    WordTable() : slots_(1 << 16, -1) {}

    int size() const { return (int)hashes_.size(); }

    // Returns the id of word p[0..n) (case-insensitive), adding it if new.
    int intern(const char* p, size_t n) {
        uint64_t h = 1469598103934665603ULL;           // FNV offset basis
        for (size_t i = 0; i < n; ++i) {
            h ^= (unsigned char)toLower(p[i]);
            h *= 1099511628211ULL;                     // FNV prime
        }
        size_t mask = slots_.size() - 1;
        size_t pos = (size_t)(h ^ (h >> 29)) & mask;
        while (slots_[pos] >= 0) {
            const int id = slots_[pos];
            if (hashes_[id] == h && sameWord(id, p, n)) return id;
            pos = (pos + 1) & mask;                    // linear probing
        }
        const int id = size();
        slots_[pos] = id;
        hashes_.push_back(h);
        start_.push_back((uint32_t)chars_.size());
        length_.push_back((uint32_t)n);
        for (size_t i = 0; i < n; ++i) chars_ += toLower(p[i]);
        if (2 * hashes_.size() > slots_.size()) grow();
        return id;
    }

private:
    bool sameWord(int id, const char* p, size_t n) const {
        if (length_[id] != n) return false;
        const char* stored = chars_.data() + start_[id];
        for (size_t i = 0; i < n; ++i)
            if (stored[i] != toLower(p[i])) return false;
        return true;
    }

    void grow() {
        std::vector<int> bigger(slots_.size() * 2, -1);
        const size_t mask = bigger.size() - 1;
        for (int id = 0; id < size(); ++id) {
            const uint64_t h = hashes_[id];
            size_t pos = (size_t)(h ^ (h >> 29)) & mask;
            while (bigger[pos] >= 0) pos = (pos + 1) & mask;
            bigger[pos] = id;
        }
        slots_.swap(bigger);
    }

    std::vector<int> slots_;          // -1 = empty, otherwise a word id
    std::vector<uint64_t> hashes_;    // per id: full 64-bit hash
    std::vector<uint32_t> start_;     // per id: position of the word in chars_
    std::vector<uint32_t> length_;    // per id: length of the word
    std::string chars_;               // all distinct words, lower-cased, concatenated
};

// ------------------------------ sentences ------------------------------

// Words that end with '.' but normally do not end a sentence.
static bool isAbbreviation(const std::string& w) {
    static const char* const list[] = {
        "Mr", "Mrs", "Ms", "Dr", "St", "Jr", "Sr", "Messrs", "Mt", "Ft",
        "Gen", "Col", "Capt", "Lieut", "Lt", "Gov", "Hon", "Rev", "Prof", "No", "vs"};
    for (const char* a : list)
        if (w == a) return true;
    // A single capital letter is an initial ("James B. Eads", "U.S.").
    return w.size() == 1 && isUpper(w[0]);
}

// Copies text[from, to) with runs of whitespace collapsed to one space, trimmed.
static std::string collapseSpaces(const std::string& s, size_t from, size_t to) {
    std::string out(to - from, '\0');             // never longer than the input
    size_t len = 0;
    bool pendingSpace = false;
    for (size_t i = from; i < to; ++i) {
        const char c = s[i];
        if (isSpace(c)) { pendingSpace = len > 0; continue; }
        if (pendingSpace) { out[len++] = ' '; pendingSpace = false; }
        out[len++] = c;
    }
    out.resize(len);
    return out;
}

// A sentence ends at '.', '!' or '?' (a run like ".." or "?!" counts as one)
// that is directly followed by whitespace and then a capital letter, digit,
// quote or bracket, unless the word before the '.' is an abbreviation.
// A terminator followed by a closing quote (`do." The`) does not end the
// sentence: the sample documents are built from paragraphs of exactly six
// sentences, and only this rule reproduces six sentences in every one of
// them. An empty line (new paragraph) and the end of the text also end a
// sentence.
std::vector<std::string> splitSentences(const std::string& text) {
    std::vector<std::string> sentences;
    const size_t n = text.size();
    size_t start = 0;

    auto emit = [&](size_t end) {
        if (end <= start) return;                 // nothing since the last boundary
        std::string s = collapseSpaces(text, start, end);
        if (!s.empty()) sentences.push_back(std::move(s));
    };

    for (size_t i = 0; i < n; ++i) {
        const char c = text[i];

        // Paragraph break: newline, optional spaces, newline.
        if (c == '\n') {
            size_t j = i + 1;
            while (j < n && (text[j] == ' ' || text[j] == '\t' || text[j] == '\r')) ++j;
            if (j < n && text[j] == '\n') { emit(i); start = j + 1; i = j; }
            continue;
        }
        if (!isTerminator(c)) continue;

        // Absorb a run of terminators ("..", "?!"); it must be followed by whitespace.
        size_t end = i + 1;
        while (end < n && isTerminator(text[end])) ++end;
        if (end < n && !isSpace(text[end])) { i = end - 1; continue; }   // e.g. "1.5", "U.S.", `."`

        size_t next = end;
        while (next < n && isSpace(text[next])) ++next;
        bool boundary = (next == n);
        if (!boundary) {
            const char d = text[next];
            boundary = isUpper(d) || isDigit(d) || d == '"' || d == '\'' || d == '(' || d == '[';
        }
        if (boundary && c == '.') {
            // The word right before the '.' decides whether it is an abbreviation.
            size_t wStart = i;
            while (wStart > start && (isUpper(text[wStart - 1]) || isLower(text[wStart - 1]))) --wStart;
            if (isAbbreviation(text.substr(wStart, i - wStart))) boundary = false;
        }
        if (boundary) {
            emit(end);
            start = next;
        }
        i = end - 1;
    }
    emit(n);
    return sentences;
}

// -------------------------------- words --------------------------------

// A word is a run of letters/digits; an apostrophe or hyphen between two
// such characters stays inside the word ("Majesty's", "well-nigh").
// Calls onWord(start, length) for every word of s.
template <typename OnWord>
static void scanWords(const std::string& s, OnWord onWord) {
    const size_t n = s.size();
    size_t i = 0;
    while (i < n) {
        if (!isWordChar(s[i])) { ++i; continue; }
        const size_t start = i;
        while (i < n && (isWordChar(s[i]) ||
                         ((s[i] == '\'' || s[i] == '-') && i + 1 < n && isWordChar(s[i + 1]))))
            ++i;
        onWord(start, i - start);
    }
}

std::vector<std::string> splitWords(const std::string& s) {
    std::vector<std::string> words;
    scanWords(s, [&](size_t start, size_t len) { words.push_back(s.substr(start, len)); });
    return words;
}

// ------------------------------- loading -------------------------------

// Reads a whole file into `out` with one fread call.
static bool readFile(const fs::path& path, std::string& out) {
    std::error_code ec;
    const uintmax_t size = fs::file_size(path, ec);
    if (ec) return false;
    std::FILE* f = std::fopen(path.string().c_str(), "rb");
    if (!f) return false;
    out.assign((size_t)size, '\0');
    const size_t got = size > 0 ? std::fread(&out[0], 1, (size_t)size, f) : 0;
    std::fclose(f);
    out.resize(got);
    // Skip a UTF-8 byte order mark if present.
    if (out.size() >= 3 && (unsigned char)out[0] == 0xEF && (unsigned char)out[1] == 0xBB &&
        (unsigned char)out[2] == 0xBF)
        out.erase(0, 3);
    return true;
}

static Document buildDocument(const std::string& name, const std::string& text, WordTable& words) {
    Document doc;
    doc.name = name;
    for (std::string& st : splitSentences(text)) {
        Sentence s;
        scanWords(st, [&](size_t start, size_t len) { s.ids.push_back(words.intern(st.data() + start, len)); });
        if (s.ids.empty()) continue;              // e.g. a lone "..."
        s.text = std::move(st);
        doc.sentences.push_back(std::move(s));
    }
    return doc;
}

// "document2.txt" < "document10.txt": digit runs are compared as numbers.
static bool naturalLess(const std::string& a, const std::string& b) {
    size_t i = 0, j = 0;
    while (i < a.size() && j < b.size()) {
        if (isDigit(a[i]) && isDigit(b[j])) {
            size_t i2 = i, j2 = j;
            while (i2 < a.size() && a[i2] == '0') ++i2;   // ignore leading zeros
            while (j2 < b.size() && b[j2] == '0') ++j2;
            size_t ie = i2, je = j2;
            while (ie < a.size() && isDigit(a[ie])) ++ie;
            while (je < b.size() && isDigit(b[je])) ++je;
            if (ie - i2 != je - j2) return ie - i2 < je - j2;
            for (size_t p = 0; p < ie - i2; ++p)
                if (a[i2 + p] != b[j2 + p]) return a[i2 + p] < b[j2 + p];
            i = ie; j = je;
        } else {
            if (a[i] != b[j]) return a[i] < b[j];
            ++i; ++j;
        }
    }
    return a.size() - i < b.size() - j;
}

bool loadCorpus(const std::string& folder, Corpus& corpus, std::string& error) {
    const fs::path base(folder);
    const fs::path mainPath = base / "main_doc.txt";
    const fs::path docsPath = base / "documents";
    WordTable words;

    std::string text;
    if (!readFile(mainPath, text)) {
        error = "cannot read " + mainPath.string();
        return false;
    }
    corpus.main = buildDocument("main_doc.txt", text, words);

    std::error_code ec;
    if (!fs::is_directory(docsPath, ec)) {
        error = "folder not found: " + docsPath.string();
        return false;
    }
    std::vector<std::string> names;
    for (const auto& entry : fs::directory_iterator(docsPath, ec)) {
        if (!entry.is_regular_file()) continue;
        const std::string name = entry.path().filename().string();
        const bool isTxt = name.size() > 4 && name.compare(name.size() - 4, 4, ".txt") == 0;
        if (isTxt && name[0] != '.') names.push_back(name);
    }
    std::sort(names.begin(), names.end(), naturalLess);
    if (names.empty()) {
        error = "no .txt files in " + docsPath.string();
        return false;
    }

    corpus.docs.clear();
    corpus.docs.reserve(names.size());
    for (const std::string& name : names) {
        if (!readFile(docsPath / name, text)) {
            error = "cannot read " + (docsPath / name).string();
            return false;
        }
        corpus.docs.push_back(buildDocument(name, text, words));
    }
    corpus.vocabularySize = words.size();
    return true;
}

// =====================================================================
// similarity.cpp
// The matching rule and the word-level edit distance.
//
// MATCHING RULE
//   Both sentences are compared as sequences of lower-cased words
//   (punctuation ignored). The distance between them is the optimal
//   string alignment (OSA) distance on words: the smallest number of
//       - word insertions,
//       - word deletions,
//       - word replacements,
//       - swaps of two neighbouring words
//   that turn one sentence into the other.
//   Two sentences match  <=>  distance <= allowedEdits(la, lb),
//   where allowedEdits = 30% of the word count of the longer sentence
//   (rounded down). So a 4-word sentence may differ by 1 edit, a
//   20-word sentence by 6 edits; sentences of 1-3 words must be equal.
//   (30% was chosen with tools/make_test_set.py: it finds sentences with
//   up to 3 random edits, while no two different sentences of the sample
//   documents are even within 40% of each other, so no false matches.)
// =====================================================================
#include "plagiarism.h"

#include <algorithm>

// Allowed share of edits, in percent of the longer sentence's word count.
static const int EDIT_PERCENT = 30;

int allowedEdits(int la, int lb) {
    const int longer = std::max(la, lb);
    return longer * EDIT_PERCENT / 100;          // integer arithmetic = floor
}

// A document sentence with lb words can only match if |la - lb| <= k,
// because every edit changes the length by at most one word. Longer lb
// gives a larger k, so we walk lb upwards until the length gap exceeds k.
int maxAllowedEdits(int la) {
    int best = allowedEdits(la, la);
    for (int lb = la + 1;; ++lb) {
        const int k = allowedEdits(la, lb);
        if (lb - la > k) break;
        best = std::max(best, k);
    }
    return best;
}

// ---------------------------------------------------------------------
// Full OSA distance (used by the brute-force version).
// d[i][j] = distance between the first i words of a and first j words of b
//   d[i][j] = min( d[i-1][j] + 1,                        delete a[i-1]
//                  d[i][j-1] + 1,                        insert b[j-1]
//                  d[i-1][j-1] + (a[i-1] != b[j-1]),     keep / replace
//                  d[i-2][j-2] + 1  if a[i-1]==b[j-2] and a[i-2]==b[j-1] )  swap
// Only three rows are kept: O(|a|*|b|) time, O(|b|) memory.
// ---------------------------------------------------------------------
int osaDistance(const std::vector<int>& a, const std::vector<int>& b) {
    const int n = (int)a.size(), m = (int)b.size();
    std::vector<int> prev2(m + 1), prev(m + 1), cur(m + 1);
    for (int j = 0; j <= m; ++j) prev[j] = j;
    for (int i = 1; i <= n; ++i) {
        cur[0] = i;
        for (int j = 1; j <= m; ++j) {
            int v = std::min(prev[j] + 1, cur[j - 1] + 1);
            v = std::min(v, prev[j - 1] + (a[i - 1] != b[j - 1] ? 1 : 0));
            if (i > 1 && j > 1 && a[i - 1] == b[j - 2] && a[i - 2] == b[j - 1])
                v = std::min(v, prev2[j - 2] + 1);
            cur[j] = v;
        }
        std::swap(prev2, prev);
        std::swap(prev, cur);
    }
    return prev[m];
}

// ---------------------------------------------------------------------
// Banded OSA distance (used by the efficient version).
// If the distance is <= k, the optimal alignment never leaves the band
// |i - j| <= k, so only 2k+1 cells per row are computed: O(|a| * k).
// Values are capped at k+1 ("too far"), and we stop early as soon as a
// whole row is > k, because values never decrease further down.
// ---------------------------------------------------------------------
int boundedOsaDistance(const std::vector<int>& a, const std::vector<int>& b, int k) {
    const int n = (int)a.size(), m = (int)b.size();
    const int TOO_FAR = k + 1;
    if (n - m > k || m - n > k) return TOO_FAR;            // length filter

    // Reused buffers: the program is single-threaded.
    static std::vector<int> buf0, buf1, buf2;
    if ((int)buf0.size() < m + 2) { buf0.resize(m + 2); buf1.resize(m + 2); buf2.resize(m + 2); }
    int* prev2 = buf0.data();
    int* prev = buf1.data();
    int* cur = buf2.data();

    // Row 0: d[0][j] = j inside the band.
    for (int j = 0; j <= std::min(m, k); ++j) prev[j] = j;
    if (k + 1 <= m) prev[k + 1] = TOO_FAR;

    for (int i = 1; i <= n; ++i) {
        const int lo = std::max(1, i - k), hi = std::min(m, i + k);
        cur[0] = (i <= k) ? i : TOO_FAR;                     // column 0
        if (lo > 1) cur[lo - 1] = TOO_FAR;                   // left edge of band
        int rowMin = cur[0];
        for (int j = lo; j <= hi; ++j) {
            int v = std::min(prev[j] + 1, cur[j - 1] + 1);
            v = std::min(v, prev[j - 1] + (a[i - 1] != b[j - 1] ? 1 : 0));
            if (i > 1 && j > 1 && a[i - 1] == b[j - 2] && a[i - 2] == b[j - 1])
                v = std::min(v, prev2[j - 2] + 1);
            if (v > TOO_FAR) v = TOO_FAR;
            cur[j] = v;
            if (v < rowMin) rowMin = v;
        }
        if (hi + 1 <= m) cur[hi + 1] = TOO_FAR;              // right edge of band
        if (rowMin > k) return TOO_FAR;                      // early termination
        int* t = prev2; prev2 = prev; prev = cur; cur = t;   // rotate rows
    }
    return std::min(prev[m], TOO_FAR);
}

// ---------------------------------------------------------------------
// Edit description for printing: full DP table, then walk back from the
// bottom-right corner and name every step that costs 1.
// Source = document sentence, target = main_doc sentence, so the words
// are reported as "what the copier did to the original sentence".
// ---------------------------------------------------------------------
std::string describeEdits(const Sentence& docSentence, const Sentence& mainSentence) {
    const std::vector<int>& x = docSentence.ids;
    const std::vector<int>& y = mainSentence.ids;
    const int n = (int)x.size(), m = (int)y.size();
    std::vector<std::vector<int>> d(n + 1, std::vector<int>(m + 1, 0));
    for (int i = 0; i <= n; ++i) d[i][0] = i;
    for (int j = 0; j <= m; ++j) d[0][j] = j;
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= m; ++j) {
            int v = std::min(d[i - 1][j] + 1, d[i][j - 1] + 1);
            v = std::min(v, d[i - 1][j - 1] + (x[i - 1] != y[j - 1] ? 1 : 0));
            if (i > 1 && j > 1 && x[i - 1] == y[j - 2] && x[i - 2] == y[j - 1])
                v = std::min(v, d[i - 2][j - 2] + 1);
            d[i][j] = v;
        }

    // Words as written (same tokenizer as the ids, so positions line up).
    const std::vector<std::string> xw = splitWords(docSentence.text);
    const std::vector<std::string> yw = splitWords(mainSentence.text);
    auto q = [](const std::string& w) { return "\"" + w + "\""; };
    std::vector<std::string> ops;                       // collected backwards
    int i = n, j = m;
    while (i > 0 || j > 0) {
        if (i > 0 && j > 0 && x[i - 1] == y[j - 1] && d[i][j] == d[i - 1][j - 1]) {
            --i; --j;                                   // same word
        } else if (i > 1 && j > 1 && x[i - 1] == y[j - 2] && x[i - 2] == y[j - 1] &&
                   d[i][j] == d[i - 2][j - 2] + 1) {
            ops.push_back("swapped " + q(xw[i - 2]) + " and " + q(xw[i - 1]));
            i -= 2; j -= 2;
        } else if (i > 0 && j > 0 && d[i][j] == d[i - 1][j - 1] + 1) {
            ops.push_back("replaced " + q(xw[i - 1]) + " with " + q(yw[j - 1]));
            --i; --j;
        } else if (i > 0 && d[i][j] == d[i - 1][j] + 1) {
            ops.push_back("deleted " + q(xw[i - 1]));
            --i;
        } else {
            ops.push_back("inserted " + q(yw[j - 1]));
            --j;
        }
    }
    std::string out;
    for (int t = (int)ops.size() - 1; t >= 0; --t) {
        if (!out.empty()) out += "; ";
        out += ops[t];
    }
    return out;
}

// ----------------------------- MatchTable -----------------------------

void MatchTable::init(int numDocs, int numMainSentences) {
    best.assign(numDocs, std::vector<Match>(numMainSentences));
    for (int d = 0; d < numDocs; ++d)
        for (int i = 0; i < numMainSentences; ++i) best[d][i].mainIdx = i;
}

void MatchTable::offer(int doc, int mainIdx, int docSentIdx, int distance) {
    Match& m = best[doc][mainIdx];
    if (m.docSentIdx < 0 || distance < m.distance ||
        (distance == m.distance && docSentIdx < m.docSentIdx)) {
        m.docSentIdx = docSentIdx;
        m.distance = distance;
    }
}

bool MatchTable::operator==(const MatchTable& other) const {
    if (best.size() != other.best.size()) return false;
    for (size_t d = 0; d < best.size(); ++d) {
        if (best[d].size() != other.best[d].size()) return false;
        for (size_t i = 0; i < best[d].size(); ++i) {
            const Match& p = best[d][i];
            const Match& q = other.best[d][i];
            if (p.docSentIdx != q.docSentIdx || p.distance != q.distance) return false;
        }
    }
    return true;
}
src/brute_force.cpp
// =====================================================================
// brute_force.cpp
// Brute-force version: every sentence of main_doc.txt is compared with
// every sentence of every document using the full edit-distance table.
//
//   for each sentence a of main_doc.txt                 (n sentences)
//       for each document D                             (m documents)
//           for each sentence b of D                    (s sentences per doc)
//               dist = osaDistance(a, b)                (O(w^2) for w words)
//               if dist <= allowedEdits(|a|, |b|): record (D, a, b, dist)
//
// Time: O(n * m * s * w^2)
// =====================================================================
#include "plagiarism.h"

MatchTable runBruteForce(const Corpus& corpus) {
    const std::vector<Sentence>& mainSentences = corpus.main.sentences;
    MatchTable table;
    table.init((int)corpus.docs.size(), (int)mainSentences.size());

    for (int i = 0; i < (int)mainSentences.size(); ++i) {
        const std::vector<int>& a = mainSentences[i].ids;
        for (int d = 0; d < (int)corpus.docs.size(); ++d) {
            const std::vector<Sentence>& docSentences = corpus.docs[d].sentences;
            for (int s = 0; s < (int)docSentences.size(); ++s) {
                const std::vector<int>& b = docSentences[s].ids;
                const int dist = osaDistance(a, b);
                if (dist <= allowedEdits((int)a.size(), (int)b.size()))
                    table.offer(d, i, s, dist);
            }
        }
    }
    return table;
}
src/efficient.cpp
// =====================================================================
// efficient.cpp
// Efficient version: inverted index of main_doc.txt + pigeonhole filter
// + banded edit distance. Every document sentence is read only once.
//
// 1. INDEX the small side, main_doc.txt  (O(n * w))
//      postings[word] = main sentences that contain the word (each once)
//      byLength[L]    = main sentences with exactly L words
//
// 2. SCAN every sentence b of every document once, k = maxAllowedEdits(|b|).
//    Pigeonhole argument: if b matches a main sentence a, at most k edits
//    were made and every edit removes at most one word of b from a (a swap
//    removes none). So among ANY k+1 distinct words of b, at least one
//    also occurs in a.
//      - If k+1 distinct words of b occur nowhere in main_doc.txt, b
//        cannot match anything and is skipped. This is the case for
//        almost every sentence, usually after reading only a few words.
//      - Otherwise the probe set is: the words of b missing from main_doc
//        (empty posting lists) plus the rarest present words, k+1 in all.
//        Candidates = main sentences in the posting lists of the probe set.
//      - If b has at most k distinct words (very short sentences) the
//        argument does not apply; then every main sentence whose length is
//        within k of |b| is a candidate (from byLength).
//    No true match is ever lost, so the result equals the brute force.
//
// 3. VERIFY each candidate with three checks, cheapest first:
//      length filter       ||a| - |b|| <= k                      O(1)
//      bag-of-words filter max(|a|,|b|) - common words <= k      O(w)
//      banded edit distance boundedOsaDistance(a, b, k) <= k     O(w * k)
// =====================================================================
#include "plagiarism.h"

#include <algorithm>

namespace {

class MainDocIndex {
public:
    MainDocIndex(const Document& mainDoc, int vocabularySize)
        : main_(mainDoc), postings_(vocabularySize), wordSeen_(vocabularySize, -1) {
        const std::vector<Sentence>& sentences = main_.sentences;
        for (int i = 0; i < (int)sentences.size(); ++i) {
            for (int w : sentences[i].ids) {
                if (wordSeen_[w] == i) continue;          // each sentence once per word
                wordSeen_[w] = i;
                postings_[w].push_back(i);
            }
            const int len = (int)sentences[i].ids.size();
            if (len >= (int)byLength_.size()) byLength_.resize(len + 1);
            byLength_[len].push_back(i);
            sortedIds_.push_back(sentences[i].ids);
            std::sort(sortedIds_.back().begin(), sortedIds_.back().end());
        }
        std::fill(wordSeen_.begin(), wordSeen_.end(), -1);
        checkedBy_.assign(sentences.size(), -1);
    }

    // Finds the main sentences that match sentence `s` of document `doc`.
    // `stamp` must be different for every call (used to de-duplicate).
    void search(int doc, int s, const std::vector<int>& b, int stamp, MatchTable& table) {
        const int k = maxAllowedEdits((int)b.size());

        // Distinct words of b, split into "missing from main_doc" and "present".
        // As soon as k+1 distinct words are missing, b cannot match anything
        // (pigeonhole), so we stop reading it.
        int missing = 0;
        present_.clear();
        for (int w : b) {
            if (wordSeen_[w] == stamp) continue;
            wordSeen_[w] = stamp;
            if (!postings_[w].empty()) present_.push_back(w);
            else if (++missing > k) return;
        }
        const int distinct = missing + (int)present_.size();
        sortedB_.assign(b.begin(), b.end());             // for the bag-of-words filter
        std::sort(sortedB_.begin(), sortedB_.end());

        if (distinct >= k + 1) {
            const int probes = k + 1 - missing;           // rarest present words to probe
            std::partial_sort(present_.begin(), present_.begin() + probes, present_.end(),
                              [this](int x, int y) { return postings_[x].size() < postings_[y].size(); });
            for (int t = 0; t < probes; ++t)
                for (int a : postings_[present_[t]]) verify(a, doc, s, b, stamp, table);
        } else {
            // Too few distinct words for the pigeonhole argument: length buckets.
            const int lb = (int)b.size();
            for (int len = std::max(0, lb - k); len <= lb + k && len < (int)byLength_.size(); ++len)
                for (int a : byLength_[len]) verify(a, doc, s, b, stamp, table);
        }
    }

private:
    void verify(int a, int doc, int s, const std::vector<int>& b, int stamp, MatchTable& table) {
        if (checkedBy_[a] == stamp) return;               // already checked for this b
        checkedBy_[a] = stamp;
        const std::vector<int>& av = main_.sentences[a].ids;
        const int la = (int)av.size(), lb = (int)b.size();
        const int k = allowedEdits(la, lb);
        if (la - lb > k || lb - la > k) return;                       // length filter
        if (std::max(la, lb) - commonWords(sortedIds_[a], sortedB_) > k) return;  // bag filter
        const int dist = boundedOsaDistance(av, b, k);
        if (dist <= k) table.offer(doc, a, s, dist);
    }

    // Size of the multiset intersection of two sorted word lists, O(|x|+|y|).
    // Every edit adds at most one non-shared word, so
    // distance >= max(|a|, |b|) - commonWords(a, b): a cheap lower bound.
    static int commonWords(const std::vector<int>& x, const std::vector<int>& y) {
        int i = 0, j = 0, common = 0;
        while (i < (int)x.size() && j < (int)y.size()) {
            if (x[i] < y[j]) ++i;
            else if (y[j] < x[i]) ++j;
            else { ++common; ++i; ++j; }
        }
        return common;
    }

    const Document& main_;
    std::vector<std::vector<int>> postings_;   // word id -> main sentences containing it
    std::vector<std::vector<int>> byLength_;   // word count -> main sentences
    std::vector<int> wordSeen_;                // word id -> last stamp (distinct words of b)
    std::vector<int> checkedBy_;               // main sentence -> last stamp that verified it
    std::vector<std::vector<int>> sortedIds_;  // main sentence -> its word ids, sorted
    std::vector<int> present_;                 // scratch: distinct words of b found in main_doc
    std::vector<int> sortedB_;                 // scratch: word ids of b, sorted
};

}  // namespace

MatchTable runEfficient(const Corpus& corpus) {
    MatchTable table;
    table.init((int)corpus.docs.size(), (int)corpus.main.sentences.size());

    MainDocIndex index(corpus.main, corpus.vocabularySize);
    int stamp = 0;
    for (int d = 0; d < (int)corpus.docs.size(); ++d) {
        const std::vector<Sentence>& sentences = corpus.docs[d].sentences;
        for (int s = 0; s < (int)sentences.size(); ++s) index.search(d, s, sentences[s].ids, stamp++, table);
    }
    return table;
}

// =====================================================================
// output.cpp
// Ranks the documents and prints one block per document:
//
// 1) document7.txt   similarity 42.5%   (17 of 40 sentences)
//    "<sentence in main_doc.txt>"
//    "<matching sentence in document7.txt>"   [edited: ...]
//    ... up to the 5 most similar sentence pairs
//
// Similarity rate = matched sentences of main_doc.txt / all sentences
// of main_doc.txt * 100, one decimal.
// =====================================================================
#include "plagiarism.h"

#include <algorithm>
#include <cstdio>

static const int MAX_PAIRS_SHOWN = 5;

// Percentage with one decimal, rounded half up using integers only.
static std::string percent(int part, int whole) {
    if (whole == 0) return "0.0";
    const long long tenths = ((long long)part * 1000 + whole / 2) / whole;
    return std::to_string(tenths / 10) + "." + std::to_string(tenths % 10);
}

// Pair p is more similar than q if its distance relative to the longer
// sentence is smaller: dp/Lp < dq/Lq  <=>  dp*Lq < dq*Lp.
static bool moreSimilar(const Match& p, int lp, const Match& q, int lq) {
    const long long left = (long long)p.distance * lq, right = (long long)q.distance * lp;
    if (left != right) return left < right;
    return p.mainIdx < q.mainIdx;
}

void printResults(const Corpus& corpus, const MatchTable& table) {
    const std::vector<Sentence>& mainSentences = corpus.main.sentences;
    const int n = (int)mainSentences.size();
    const int numDocs = (int)corpus.docs.size();

    // Matched main sentences per document.
    std::vector<std::vector<Match>> matched(numDocs);
    for (int d = 0; d < numDocs; ++d)
        for (const Match& m : table.best[d])
            if (m.docSentIdx >= 0) matched[d].push_back(m);

    // Rank documents: most matched sentences first, ties in file order.
    std::vector<int> order(numDocs);
    for (int d = 0; d < numDocs; ++d) order[d] = d;
    std::stable_sort(order.begin(), order.end(),
                     [&](int x, int y) { return matched[x].size() > matched[y].size(); });

    for (int rank = 0; rank < numDocs; ++rank) {
        const int d = order[rank];
        const Document& doc = corpus.docs[d];
        std::vector<Match>& pairs = matched[d];
        std::printf("%d) %s   similarity %s%%   (%d of %d sentences)\n", rank + 1, doc.name.c_str(),
                    percent((int)pairs.size(), n).c_str(), (int)pairs.size(), n);

        // The most similar pairs first.
        auto pairLength = [&](const Match& m) {
            return std::max(mainSentences[m.mainIdx].ids.size(),
                            doc.sentences[m.docSentIdx].ids.size());
        };
        std::sort(pairs.begin(), pairs.end(), [&](const Match& p, const Match& q) {
            return moreSimilar(p, (int)pairLength(p), q, (int)pairLength(q));
        });

        const int shown = std::min((int)pairs.size(), MAX_PAIRS_SHOWN);
        for (int t = 0; t < shown; ++t) {
            const Sentence& ms = mainSentences[pairs[t].mainIdx];
            const Sentence& ds = doc.sentences[pairs[t].docSentIdx];
            std::printf("   \"%s\"\n", ms.text.c_str());
            if (pairs[t].distance == 0)
                std::printf("   \"%s\"\n", ds.text.c_str());
            else
                std::printf("   \"%s\"   [edited: %s]\n", ds.text.c_str(), describeEdits(ds, ms).c_str());
        }
        if ((int)pairs.size() > shown) std::printf("   ... and %d more pairs\n", (int)pairs.size() - shown);
    }

    // Sentences of main_doc.txt copied from at least one document.
    int copied = 0;
    for (int i = 0; i < n; ++i) {
        bool found = false;
        for (int d = 0; d < numDocs && !found; ++d) found = table.best[d][i].docSentIdx >= 0;
        if (found) ++copied;
    }
    std::printf("\n%d of %d sentences of main_doc.txt (%s%%) match a sentence in at least one document.\n",
                copied, n, percent(copied, n).c_str());
}
src/benchmark.cpp
// =====================================================================
// benchmark.cpp
// Empirical analysis: runs the brute-force and the efficient version on
// the first m documents for several values of m (at least 5 sizes),
// checks that both give identical results and prints the running times
// in milliseconds as a table; the same numbers are written to a CSV file
// that can be plotted for the report.
// Only the matching work is timed (the efficient time includes building
// the index); reading the files is the same for both and is excluded.
// =====================================================================
#include "plagiarism.h"

#include <algorithm>
#include <chrono>
#include <cstdio>
#include <fstream>

namespace {

double millisecondsSince(std::chrono::steady_clock::time_point start) {
    return std::chrono::duration<double, std::milli>(std::chrono::steady_clock::now() - start).count();
}

// Runs `algorithm` up to `repetitions` times and returns the fastest time.
// Very slow runs (> 3 s) are not repeated.
template <typename Algorithm>
double timeIt(Algorithm algorithm, const Corpus& corpus, int repetitions, MatchTable& result) {
    double best = -1;
    for (int r = 0; r < repetitions; ++r) {
        auto start = std::chrono::steady_clock::now();
        result = algorithm(corpus);
        const double ms = millisecondsSince(start);
        if (best < 0 || ms < best) best = ms;
        if (ms > 3000) break;
    }
    return best;
}

}  // namespace

void runBenchmark(const Corpus& corpus, int repetitions, const std::string& csvPath) {
    const int total = (int)corpus.docs.size();
    const int points = std::min(total, 8);

    std::vector<int> sizes;
    for (int p = 1; p <= points; ++p) {
        const int m = (int)((long long)total * p / points);
        if (m > 0 && (sizes.empty() || sizes.back() != m)) sizes.push_back(m);
    }

    std::ofstream csv(csvPath);
    csv << "documents,document_sentences,main_sentences,brute_force_ms,efficient_ms,speedup,same_result\n";

    std::printf("Benchmark: main_doc.txt has %d sentences, best of %d runs per size\n\n",
                (int)corpus.main.sentences.size(), repetitions);
    std::printf("%10s %12s %16s %14s %10s %8s\n", "documents", "doc sents", "brute force ms", "efficient ms",
                "speedup", "same");

    for (int m : sizes) {
        Corpus sub;
        sub.main = corpus.main;
        sub.vocabularySize = corpus.vocabularySize;
        sub.docs.assign(corpus.docs.begin(), corpus.docs.begin() + m);
        long long docSentences = 0;
        for (const Document& d : sub.docs) docSentences += (long long)d.sentences.size();

        MatchTable brute, fast;
        const double bruteMs = timeIt(runBruteForce, sub, repetitions, brute);
        const double fastMs = timeIt(runEfficient, sub, repetitions, fast);
        const bool same = (brute == fast);
        const double speedup = fastMs > 0 ? bruteMs / fastMs : 0;

        std::printf("%10d %12lld %16.2f %14.3f %9.1fx %8s\n", m, docSentences, bruteMs, fastMs, speedup,
                    same ? "yes" : "NO");
        csv << m << ',' << docSentences << ',' << sub.main.sentences.size() << ',' << bruteMs << ','
            << fastMs << ',' << speedup << ',' << (same ? "yes" : "no") << '\n';
    }
    std::printf("\nResults written to %s\n", csvPath.c_str());
}

Part 2: Report

a. Problem and approach

The program gets main_doc.txt and a folder of documents. For every document it reports what percentage of the main_doc sentences were copied from it, either exactly or with small edits, and it shows the most similar sentence pairs. We use the definition from the assignment: similarity rate = matched sentences of main_doc / all sentences of main_doc × 100, printed with one decimal.

Our main idea is to turn every sentence into a list of integer word ids and call two sentences a match when their word-level edit distance is small. The brute force computes this distance for every pair of sentences. The efficient version gives the same answer but computes almost no distances. It builds an index of the words in main_doc, reads each document sentence once, and uses a pigeonhole argument and two cheap lower bounds to throw away the pairs that cannot match. Only the few pairs that are left get a banded edit distance. The compare and benchmark modes run both versions on the same input and check that they print the same result.

Matching rule. A word is a run of letters and digits. An apostrophe or hyphen inside a word stays in it ("Majesty's", "well-nigh"). Case and punctuation are ignored. As the distance we use the optimal string alignment (OSA) distance on words, which is the smallest number of word insertions, deletions, replacements and swaps of two neighbouring words. These are the same four kinds of edits the task describes. Sentences a and b match if dist(a,b) ≤ ⌊0.30 · max(|a|,|b|)⌋. So a sentence of 1 to 3 words has to be identical, a 10-word sentence can have 3 edits and a 30-word sentence 9. We started with 25% and moved to 30% after testing on generated sets (section e). With 30% we found sentences that had up to 3 random edits, and we checked that no two different sentences in the sample documents are even within 40% of each other, so we did not get any false matches. A main sentence is counted once per document; if it matches several sentences there, we keep the closest one.

Sentence splitting. A sentence ends at ., ! or ? when the next thing after the whitespace is a capital letter, a digit, a quote or a bracket. We do not split after Mr., St., a few other common abbreviations, or a single capital letter (U.S., James B. Eads). We also do not split when a closing quote comes right after the full stop (do." The), and an empty line always ends a sentence. We got this rule from the data. While looking at the sample documents we noticed that every paragraph has exactly six sentences, so the documents were clearly built from the test generator's own sentences. Only this rule gives six sentences in all 320 paragraphs. A simple split on every ". " gives 7 or 8 in eleven of them, and our first version, which also split after closing quotes, was wrong in a few paragraphs too. Getting the boundaries right matters because a sentence that is cut in two changes the sentence count and can hide a copied sentence.

b. Data structures and algorithms

1. Tokenizer and our own hash table (word to id). One pass over the text splits it into sentences and words. We do not use find, indexOf or regex anywhere. Each lower-cased word gets a small integer id from a hash table we wrote ourselves. It uses the 64-bit FNV-1a hash and open addressing with linear probing, and the table doubles when it is half full. After this step a sentence is a vector<int> and comparing two words is a single integer comparison. We chose a hash table because a lookup is O(1) on average, while std::map or a BST needs O(log V) string comparisons. Integer ids also make all later steps cheaper than working with strings. In our first version we stored every word as a separate std::string, and reading 200 documents took about 94 ms. With the hash table and no per-word strings it went down to about 48 ms.

intern(word):  h ← FNV1a(lowercase(word));  p ← h mod size
               while slot[p] not empty: if stored(slot[p]) = word: return slot[p];  p ← p+1 mod size
               slot[p] ← new id;  if count > size/2: double size and re-insert;  return new id

2. Word-level OSA edit distance (dynamic programming). We picked OSA because it counts exactly the four allowed edits. Plain Levenshtein counts a swap as 2 edits, and bag-of-words measures like Jaccard or cosine cannot see a swap at all. We work on words instead of characters, so the sequences are about 6 times shorter.

d[i][0] = i,  d[0][j] = j
d[i][j] = min( d[i-1][j] + 1,  d[i][j-1] + 1,  d[i-1][j-1] + [a_i ≠ b_j],
               d[i-2][j-2] + 1  if a_i = b_(j-1) and a_(i-1) = b_j )        # swap
answer d[|a|][|b|]   (only 3 rows are stored)

3. Brute force.

for each sentence a of main_doc:  for each document D:  for each sentence b of D:
    dist ← OSA(a, b)                                        # full table, O(|a|·|b|)
    if dist ≤ allowed(|a|,|b|): keep (D, a, b, dist) if it is the best pair of a in D

4. Efficient version. It has four parts.

(i) An inverted index of main_doc: postings[word] is the list of main sentences that contain the word, and we also keep each main sentence's word ids in sorted order. Our first efficient version indexed all the documents instead. That index is much bigger and was slower to build, so we switched to indexing main_doc, which is the small side, and reading the documents one sentence at a time.

(ii) The pigeonhole filter. Suppose b matches a with at most k edits. Each edit can remove at most one word of b from a (a swap removes none), so if we take any k+1 different words of b, at least one of them is in a. This gives us two shortcuts. If k+1 different words of b do not appear anywhere in main_doc, b cannot match anything and we skip it. If not, we only look at the main sentences in the posting lists of the k+1 rarest words of b. Because of the argument above we never lose a real match, so the result is the same as the brute force.

(iii) Two cheap filters that never reject a real match, the cheaper one first. The length filter uses the fact that each edit changes the length by at most one word. The bag-of-words filter uses dist ≥ max(|a|,|b|) minus the number of common words; we count the common words by merging the two sorted id lists in O(w).

(iv) Banded OSA. If the distance is at most k, the best alignment never leaves the band |i − j| ≤ k, so we only fill 2k+1 cells per row. We also stop as soon as a whole row is bigger than k.

build postings[word], sorted ids of every main sentence                    # once, O(n·w log w)
for each document D, for each sentence b of D:
    k ← largest allowed(|a|,|b|) over all |a| that pass the length filter
    scan distinct words of b; missing ← words with empty postings;  if missing > k: next b
    probes ← missing words + (k+1 − missing) rarest present words of b
    for each main sentence a in postings of probes (each a once):
        k_ab ← allowed(|a|,|b|)
        if | |a|−|b| | > k_ab: continue                                      # length filter
        if max(|a|,|b|) − common(sorted a, sorted b) > k_ab: continue        # bag-of-words filter
        if bandedOSA(a, b, k_ab) ≤ k_ab: keep the pair (best per (D, a))
(if b has ≤ k distinct words the pigeonhole rule cannot be applied: all a with ||a|−|b|| ≤ k are candidates)

We also thought about other options. Rabin-Karp or hashing whole sentences only finds exact copies. Hashing word n-grams (shingles) needs 3k+1 probes per sentence because one edit can break up to 3 bigrams, and common bigrams like "of the" have very long lists. With single words and "rarest first" we only need k+1 probes. MinHash and LSH are probabilistic, so they can miss copies. Suffix trees and suffix arrays find exact substrings, not edited sentences.

5. Output. A MatchTable (documents × main sentences) stores the best pair for each cell. We sort the documents by number of matched sentences and the pairs inside a document by dist/max(|a|,|b|). The best 5 pairs are printed, and for edited ones we get the edit list by walking back through the DP table.

c. Complexity analysis

We use these names: n = sentences in main_doc, m = number of documents, s = sentences per document, S = m·s = all document sentences, w = words per sentence (maximum), W ≈ S·w = all words in the documents, C = characters in all files, V = number of different words, k = allowed edits ≤ 0.3 · longer length (at most 0.43·w after the length filter), c = candidates per document sentence and M = matching pairs.

In the worst case, every document sentence is almost the same as every main sentence. Then all pairs pass the filters (D = n·S) and the efficient version is also O(n·S·w²). We do not think any exact algorithm can avoid this, because in that input every pair really has to be reported or ruled out. Real text is very different. The brute force always does n·S full DPs of w² cells, but our version does O(w) work for most document sentences and O(w) per candidate, and only computes a DP for the M real matches. We counted this on the 200-document set with the 30-sentence main_doc. The brute force computes 600 000 full DPs. Our version skips 6 670 of the 20 000 document sentences with the pigeonhole test alone, looks at 47 440 candidates (the length filter removes 29 580 and the bag-of-words filter 17 660) and computes only 200 banded DPs, which are exactly the 200 matching pairs. So in practice it costs O(C + S·w log w + S·c·w + M·w²) with c ≈ 2.4, much smaller than n. That is linear in the input size, while the brute force grows with n·S·w². Both versions use O(C + V + n·w + m·n) memory.

e. Results

On the sample set we find all 20 copied sentences (13 exact and 7 edited) and no false matches. The ranking and the rates are the same as in expected_output.txt: document18 26.7% (8/30), document14 16.7% (5/30), document20 13.3% (4/30), document3 6.7% (2/30), document4 3.3% (1/30), and 0.0% for all other documents. For all 7 edited sentences our edit lists contain the same edits as the expected output; we just list them in the order they appear in the sentence.

Some correct matches:

  • Exact copy from document18: "This fault should not be committed in dealing with a subject that will before many years affect so vitally thousands of our people." The distance is 0.
  • A replacement and a swap (2 edits in 23 words, 6 allowed). main_doc has "The report of the Civil Service Commission must receive the attention careful ..." and document18 has "... should receive the careful attention ...". We print replaced "should" with "must"; swapped "careful" and "attention". In OSA the swap costs 1 edit; Levenshtein would count it as 2.
  • A deletion (1 edit): "With the possession of such a station the United States, ..." against document14's "... a station by the United States, ...". We print deleted "by".

To test harder cases we used make_test_set.py accuracy. It copies 40 sentences into a new main_doc and gives each one 0 to 3 random insertions, deletions, replacements or swaps. It also adds 20 sentences from documents that are left out, so they appear nowhere. We ran 10 seeds per setting. With copied sentences of at least 10 words we found 800 out of 800. With sentences of at least 6 words we found 798 out of 800. None of the runs had a false match. We also tried a 230-sentence main_doc with 150 copied sentences, and the program found all 150 and ranked the documents correctly.

The two sentences we missed were these:

  • "In invaded canals solicitude intense pervaded the nation." against the original "In that crisis intense solicitude pervaded the nation." That is 3 edits (2 replacements and 1 swap) in an 8-word sentence, so 37.5%, and our rule allows 30%.
  • "It term frequented transmitted to Congress." against "It is herewith transmitted to Congress." That is 2 edits in 6 words, and only 1 is allowed.

Both are short sentences where almost half of the words changed, which we would not call a small edit any more. If we allowed more edits we would find them, but we would also start accepting unrelated short sentences. The rule also handles similar State of the Union phrases well. For example, "These treaties and conventions will be laid before the Senate for ratification." and a document's "The articles agreed upon will immediately be laid before the Senate for their consideration." have distance 7 (4 allowed), so we do not report them, and that is right because one is not a copy of the other. Another way to miss a sentence would be splitting sentences differently from the test generator, for example at an unusual abbreviation, because then the sentence is cut in two. This is why we spent time matching the generator's splitting rule (section a).
